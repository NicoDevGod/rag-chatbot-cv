# Lessons learned across Nicolas's AI projects

Lessons learned: 1. Lightweight in production, heavy only in development. PyTorch, sentence-transformers and Ultralytics are used to train and test locally, while ONNX Runtime and FastEmbed run on the server, so there is no torch in the final deploy.

Lessons learned: 2. Pin versions and do not trust "latest". Nicolas fixes Python 3.10 and exact versions in requirements.txt because free tiers change the default Python version without notice, which silently breaks builds.

Lessons learned: 3. "It builds" is not "it works". Several projects looked finished after the build but failed at real runtime (memory, a schema crash, an infinite loop), so every one was tested with a real request against the deployed server.

Lessons learned: 4. Free tiers have real limits: 512 MB of RAM, cold starts of 30 to 100 seconds, and pricing that changes (Hugging Face Spaces stopped being free for Gradio). He designs for those limits instead of assuming them away.

Lessons learned: 5. Code or behavior generated by an LLM is not safe by default. An agent that builds expressions for eval() is a code-execution vulnerability, so the tool agent uses a restricted ast evaluator. And not every bug is fixed in code: sometimes the real fix is the prompt.

Lessons learned: 6. Not every problem needs deep learning. The movie recommender uses sparse matrices and cosine similarity with no neural network, and it was the only deploy without bugs.

Lessons learned: 7. Reimplementing a small function can beat installing a whole library: a safe ast calculator instead of eval(), per-query similarity instead of a precomputed matrix, hand-written IoU and NMS instead of torchvision, and a hand-written decode loop instead of transformers.

Lessons learned: 8. Measure in the real environment instead of reasoning from another one. The LoRA project seemed fixed with ONNX but kept crashing on Render until memory logging inside the production container showed that importing torch alone cost 100 to 200 MB.

Skills: Nicolas's AI skills include retrieval-augmented generation, embeddings and vector stores, transfer learning, computer vision (classification and object detection), function-calling agents, collaborative filtering recommenders, LoRA fine-tuning, ONNX export and INT8 quantization, memory profiling and debugging of deployed ML services, and building Gradio demos. His earlier background is full-stack web development (React, Astro, ASP.NET, SQL Server).
